# A 股量化选股回测系统（LSTM-Attention + 强化学习对照）

从数据获取到绩效归因的完整量化回测 pipeline，全部基于真实行情数据，可一键复现。

## 核心结论（诚实版）

- 样本外（2023-07 ~ 2026-09，完全未见数据）年化收益 **4.3%**，较 40 只成分股等权基准（2.4%）超额 **1.9 pp**，最大回撤 25.9%。
- **但** 3 组随机种子重复实验的样本外年化为 4.3% / 6.4% / **-6.2%**（标准差 5.5%），未能稳定超越沪深300（5.3%）。
- 判断：纯价格特征下大盘股横截面信号不足以覆盖交易成本与模型不确定性。这个负结果是本研究最重要的发现——它说明"跑回测跑出正收益"很容易是噪声，严格的多种子验证是必须的。

## 项目结构

```
quant-drl/
├── fetch_data.py   # 数据获取：腾讯行情接口，按年分段拉取，后复权落盘缓存
├── features.py     # 特征工程：12 维时序特征 + 沪深300 市场上下文，防前视设计
├── env.py          # 交易环境：多头组合配置，真实交易成本（约 15bp/单位换手）

├── train.py        # 三种训练方案：监督学习打分（主）/ REINFORCE / DQN（对照）
├── plot.py         # 净值曲线与多种子敏感性图
└── data/           # 原始行情缓存（40 只成分股 + 沪深300 ETF，csv）
```

## 三个关键工程决策

1. **后复权而非前复权**：长期高分红个股（如贵州茅台）的前复权价会出现负数
   （2015 年前复权价 -143 元），收益率完全失真。后复权价格恒为正，且收益率等价于
   含分红再投资的总收益。
2. **周频调仓 + 真实成本**：日频调仓的换手成本（年化 40%+）会吞噬一切收益；
   周频（5 日）是 A 股实务上常见的频率。成本按佣金 2.5bp + 印花税 5bp + 滑点 5bp
   建模，单次换手约 15bp。
3. **防前视偏差**：所有特征只使用 t 日及之前的信息；标准化参数仅在训练集拟合；
   测试区间与训练区间严格时序隔离。

## 三种方法的对照（这是本项目最有意思的部分）

| 方法 | 信用分配（credit assignment） | 样本外表现 |
|---|---|---|
| DQN（每只股票独立决策，共享组合奖励） | 混乱：单只股票无法从组合级奖励判断自身贡献 | 学到噪声交易，年化 -10% |
| REINFORCE（联合选股动作） | 正确：整个组合作为一个动作 | 退化陷阱：学会"什么都不选"规避换手惩罚 |
| 监督学习打分 + Top-K（主方案） | 天然正确：直接回归横截面超额收益 | 年化 4.3%（seed 42），但多种子不稳定 |

DQN 和 REINFORCE 的失败模式都有诊断记录（见 `train.py` 注释），本身也是
"强化学习在低信噪比金融数据上的局限"的实证。

## 复现步骤

```bash
pip install akshare pandas numpy matplotlib torch
python fetch_data.py      # 拉取行情（约 4 分钟，已缓存则跳过）
python train.py 15 sl     # 监督学习方案（主）
python train.py 20 pg     # REINFORCE 对照
python train.py 50 dqn    # DQN 对照
python plot.py            # 生成图表
```

多种子：`python train.py 15 sl 42,7,2024`

## 改进方向

- 特征层面：加入基本面、资金流、龙虎榜等非价格特征（纯价格特征信噪比过低）
- 约束层面：给策略加换手预算约束（turnover budget）而非仅靠成本惩罚
- 验证层面：扩大股票池至中证 500 / 全市场，检验信号在小盘股上是否更强
- 统计层面：更多种子 + 区块自助法（block bootstrap）检验显著性
